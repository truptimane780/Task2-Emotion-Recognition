# Speech Emotion Recognition using MFCC and LSTM

## Objective

To recognize human emotions from speech audio using deep learning.

## Dataset

RAVDESS (Ryerson Audio-Visual Database of Emotional Speech and Song).

## Emotions

- Neutral
- Calm
- Happy
- Sad
- Angry
- Fearful
- Disgust
- Surprised

## Methodology

1. Load speech audio
2. Extract MFCC features
3. Preprocess the data
4. Encode emotion labels
5. Split training and testing data
6. Train an LSTM model
7. Evaluate the model
8. Predict emotion from audio

## Technologies

- Python
- TensorFlow
- Keras
- Librosa
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- JupyterLab

## Model

LSTM (Long Short-Term Memory)

## Feature Extraction

MFCC (Mel-Frequency Cepstral Coefficients)
